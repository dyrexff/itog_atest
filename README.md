# Expense Tracker

**Автор:** Киселев Максим

## Описание программы

`Expense Tracker` — это простое графическое приложение на Python для отслеживания личных расходов.  
Приложение позволяет:
- добавлять расходы с указанием суммы, категории и даты;
- просматривать список расходов в таблице;
- фильтровать по категории и по диапазону дат;
- подсчитывать сумму расходов за выбранный период;
- сохранять данные в файл `expenses.json` и загружать при запуске.

## Требования

- Python 3.8+
- Библиотека `tkinter` (обычно входит в стандартную поставку Python)

## Как использовать

1. Установите Python (если ещё не установлен).
2. Склонируйте репозиторий:

   ```bash
   git clone https://github.com/ваш_логин/expense_tracker.git
   cd expense_tracker
   ```

3. Запустите программу:

   ```bash
   python app.py
   ```

4. В интерфейсе:
   - Введите сумму, категорию и дату в формате `ГГГГ-ММ-ДД`.
   - Нажмите кнопку **"Добавить расход"**.
   - Используйте поля фильтрации и кнопку **"Применить фильтры"** для просмотра нужных записей.

## Примеры использования и тесты

**Позитивные случаи:**
- Ввод корректной суммы (например, `500.0`), категории (`еда`) и даты (`2026-04-20`).
- Фильтрация по категории `еда` и диапазону дат с `2026-04-01` по `2026-04-30`.

**Негативные/граничные случаи:**
- Ввод отрицательной суммы или строки вместо числа — приложение показывает ошибку.
- Ввод даты в неверном формате — приложение показывает ошибку.

Тесты можно расширить в файле `tests/test_expenses.py` (аналогично примерам тестирования валидаций Python‑приложений).[web:2][web:7]
