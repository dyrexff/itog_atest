## Описание программы

Expense Tracker — это графическое приложение на Python для отслеживания личных расходов.  
Позволяет:
- добавлять расходы с указанием суммы, категории и даты;
- просматривать список расходов в таблице;
- фильтровать записи по категории и по дате;
- подсчитывать сумму расходов за выбранный период;
- сохранять данные в файл `expenses.json` и загружать их при запуске.

Приложение помогает контролировать личный бюджет и анализировать свои траты за любой период.

## Требования для запуска

Что нужно установить на компьютер:

- Python 3.8 или выше  
- Библиотеки: `tkinter` (обычно входит в стандартную поставку Python), для работы с JSON ничего дополнительно ставить не нужно.

## Как пользоваться

1. При запуске открывается окно Expense Tracker с формой для ввода:
   - **Сумма** — введите положительное число (например, `500.0`).
   - **Категория** — название категории (например, `еда`, `транспорт`, `развлечения`).
   - **Дата** — в формате `ГГГГ-ММ-ДД` (например, `2026-04-27`).
2. Нажмите кнопку **«Добавить расход»**, чтобы запись появилась в таблице.
3. В нижнем блоке можно:
   - выбрать **Категорию** для фильтрации;
   - указать **С даты** и **По дату** для фильтрации по периоду;
   - нажать **«Применить фильтры»**, чтобы обновить таблицу и сумму за период.
4. Все расходы автоматически сохраняются в файл `data/expenses.json` и подгружаются при следующем запуске.

## Примеры использования (возможные тесты)

**Позитивные случаи:**
- Ввод корректной суммы (`500.0`), категории (`еда`) и даты (`2026-04-20`).
- Фильтрация по категории `еда` и диапазону дат с `2026-04-01` по `2026-04-30`.

**Негативные/граничные случаи:**
- Ввод отрицательной суммы или строки вместо числа — приложение показывает сообщение об ошибке.
- Ввод даты в неверном формате (например, `2026/04/20`) — приложение требует формат `ГГГГ-ММ-ДД`.
- Попытка фильтрации без заполнения полей — таблица остаётся как есть, без сбоев.
